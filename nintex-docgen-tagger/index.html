Connect to Salesforce
How to get this URL:
In Salesforce, open Developer Console → Debug → Open Execute Anonymous Window, run System.debug(UserInfo.getSessionId());, copy the session ID from the log, and paste it after ?sid= in your org's URL — e.g. https://yourorg.my.salesforce.com/secur/frontdoor.jsp?sid=00D...

Sessions expire after a few hours and cannot be renewed automatically — paste a fresh URL when that happens.
Note: Switching orgs will reload your package list.
